Entry for the [One Word for the Boss](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735) bounty on make.fun.

## The word

**MEETINGHOLIC** — one word, 12 characters, describing a boss addicted to meetings: the boss who schedules meetings about meetings, whose calendar is the job.

## How it works

`main.py` (Python standard library only) writes exactly `MEETINGHOLIC` — no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt` when the variable is unset).

Run it with:

```sh
python3 main.py
```
